# Final recovery ledger: the 45 original unpublished commits

Authoritative account of every commit in the frozen manifest (`overnight-source-manifest.md`), reconciled against the **final code**, not against whether a SHA is reachable. The older `overnight-change-ledger.md` records the state at the overnight stop (its "NOT integrated" entries are historical).

**How each row was judged.** For every non-merge commit the added lines were compared with the files on this branch (`git show` of the commit against the current file), the behaviour was checked in the code and, where it matters, in a test or a real-browser run of the production build. A low line-match does not mean "missing": most of the Atlas, Comparison and Planner work was recovered by adapting it to code that had moved on. Merge commits carry no functionality of their own except conflict resolutions, which are listed per merge (`git diff-tree --cc`); their children are counted in their own rows, never twice.

**Categories:** Integrated · Already present · Superseded (replaced by an equivalent implementation on main) · Documentation-only · Deliberately excluded · Partially recovered · Unresolved. **No row is Unresolved.** Rows marked *Partially recovered* name exactly what was not taken and why; none of them is represented as a complete recovery.
